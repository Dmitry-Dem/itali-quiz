# 🚀 Future Features & Roadmap

This file contains planned features and improvements for the Italian Quiz App.

---

## 📊 Progress & Analytics

### Stats Dashboard
- [ ] **Weekly/Monthly stats dashboard**: See how many words learned, accuracy trends, most difficult categories
- [ ] **Word difficulty ranking**: Automatically mark words as "hard" based on wrong attempts, focus study sessions on these
- [ ] **Learning streaks**: Track consecutive days of studying (simple motivation)
- [ ] **Category progress bars**: Visual progress per word group (e.g., "Food: 45/60 words learned")
- [ ] **Performance insights**: "Your best category is Food (85% accuracy)"

### Study Enhancement
- [ ] **Wrong answers review**: End-of-session recap of missed words
- [ ] **Adaptive review**: Show struggling words more frequently

---

- [ ] **Audio pronunciation**: Text-to-speech for Italian words (browser native TTS)

## 🔔 User Experience

- [ ] **Study reminders**: Simple browser notifications for daily practice

## 📝 Content & Organization

- [ ] **Example sentences**: Add context for each word
- [ ] **Word families**: Group related words (mangiare → mangio, mangia, etc.)

## 🏆 Motivation & Gamification

- [ ] **Achievement badges**: "First 100 words", "Perfect week", "Category master"
- [ ] **Learning goals**: Set daily/weekly word targets
- [ ] **Challenge modes**: "Learn 20 new words this week"

---

## 🎯 Top Priority Features

If implementing in order of impact for Italian learning:

1. **Audio pronunciation** - Hearing correct pronunciation is crucial for Italian
2. **Adaptive review** - Focus on words you struggle with most  
3. **Progress dashboard** - See learning trends and stay motivated
4. **Example sentences** - Context makes words stick better
5. **Wrong answers review** - Learn from mistakes immediately
